# Phú Bà Trồng Cây

Game nông trại trên mây cho iPad, chạy offline (PWA). Đọc trước khi làm:

1. `PROJECT_RULES.md`, `QUALITY_STANDARDS.md`, `ACCEPTANCE_CHECKLIST.md`, `GAME_ROADMAP.md`, `CHANGELOG.md` — bộ quy tắc của CTO.
2. `docs/HANDOFF.md` — tiến độ và vướng mắc hiện tại.
3. `docs/GAMEPLAY_DESIGN.md`, `docs/ARCHITECTURE.md`, `docs/ART_STYLE_GUIDE.md` — thiết kế.
4. `docs/reports/` — báo cáo giao việc theo ngày.
